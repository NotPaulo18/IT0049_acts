# TSA1 – Tasks for Today Management System

A four-page task-management application developed using CodeIgniter 4 and MySQL for IT0049 Web System Technologies.

## Features

- Welcome page displaying only today’s tasks
- Complete task list ordered by task date
- Demo user profile
- About page
- Database records retrieved using CodeIgniter Models
- Shared navigation, header, and footer

## Pages

- `/` – Today’s tasks
- `/tasks` – All tasks
- `/profile` – Demo user profile
- `/about` – Application information

## Requirements

- PHP 8.1 or newer
- Composer
- MySQL or MariaDB
- XAMPP
- CodeIgniter 4
